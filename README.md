# MediCore Pharma – Pharmaceutical Distribution Site

Demo website for a pharma medicine distributor, built with React Router **v8.5.1** (framework mode), TypeScript, Tailwind CSS v4 and shadcn/ui (Radix).

Pages: Home, About Us, Products (search and category filter via URL params), Contact (server-side validated form; demo only, nothing is sent or stored).

## Scripts

| Command                           | Purpose                                                    |
| --------------------------------- | ---------------------------------------------------------- |
| `npm run dev`                     | Start the dev server                                       |
| `npm run build` / `npm start`     | Production build / serve                                   |
| `npm run typecheck`               | Generate route types and run `tsc`                         |
| `npm run lint` / `lint:fix`       | ESLint 9 (typescript-eslint, react, react-hooks, jsx-a11y) |
| `npm run format` / `format:check` | Prettier (with Tailwind class sorting)                     |

## Notes

- Product and company data are sample content in `app/data/`.
- Images live in `public/images` (Unsplash, see `CREDITS.md`).
- ESLint 9 is used because `eslint-plugin-react` and `eslint-plugin-jsx-a11y` do not yet declare support for ESLint 10.
- `app/components/ui/` is generated by shadcn and is excluded from lint and Prettier.
